Printing Press API-to-Agent Workflow

A reusable playbook for turning an OpenAPI API into a workflow-shaped CLI, installed binary, Hermes skill, and verified natural-language operating surface.

Markdown source · Hermes skill draft · Docs index

Core instruction: Do not merely wrap endpoints. Design an agent-native operational interface. Commands should map to real user workflows, return JSON by default, be safe for automation, and have a companion skill that teaches Hermes when and how to use the CLI.

1. OpenAPI to CLI

Fetch and inspect /openapi.json, group endpoints into human domains, and build a small Printing Press-style CLI.

2. CLI to Skill

Create a Hermes skill with triggers, exact commands, prerequisites, safety rules, known quirks, and workflow mappings.

3. Verify Live

Run help, health, one read-only endpoint, and one representative workflow before calling the bridge ready.

Inputs

  • OpenAPI URL
  • Optional API token
  • Desired CLI name
  • Desired workflow commands
  • Request to make the API agent-friendly

CLI Authoring Rules

Inspect the contract

curl -fsSL "$OPENAPI_URL" -o /tmp/openapi.json
jq '.info, (.paths | keys)' /tmp/openapi.json

Group routes into domains

Raw SurfaceAgent-Native Domain
/kitchen/inventory, /kitchen/matcheskitchen
/diary/{date}/entries, /stats/daily/{date}diary and stats
/reservations, /guests, /propertiesbookings, guests, or stays

Standard root flags

--json --compact --quiet --agent --base-url --token --config --timeout

Secrets and config

~/.config/<cli>/config.json
chmod 0600 ~/.config/<cli>/config.json

Support <CLI>_BASE_URL, <CLI>_TOKEN, <CLI>_CONFIG, and <CLI>_TIMEOUT. Never print bearer tokens in normal output.

Implementation order

  1. health or doctor
  2. Read-only list, get, and search commands
  3. Safe creates
  4. Updates
  5. Destructive writes only when explicitly requested

Known quirks to capture

  • Masked phone numbers may be incomplete.
  • Apple Health steps can be stale if the local cache has not synced.
  • Open Food Facts imports may contain zero-nutrient rows.
  • Local cache sync may be needed before reads reflect latest remote state.

Verification Checklist

command -v <cli>
<cli> --help
<cli> health --json
<cli> <read-command> --json
<cli> <representative-workflow> --json

The bridge is done only when a natural-language request can be translated into a successful CLI command without guessing.
